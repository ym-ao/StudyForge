# V3.1 Batch 3 — Numerical template authoring

## Implemented

- Added a numerical-template authoring panel to the existing question editor when the selected question type is Numerical.
- Supports question and explanation placeholders, variable rows (`name,min,max,decimals,unit`), one constraint expression per line, answer formula, answer unit and absolute tolerance.
- Added deterministic seeded preview showing the generated prompt, computed answer and substituted explanation.
- Added Draft and Verified authoring states. The state is stored in the versioned numerical-template payload; older payloads without this field decode as Draft.
- Template formula/variable validation is performed through `NumericalTemplateEngine`; invalid edits block saving the Numerical question until corrected.
- Valid templates are written to the dedicated `numerical_template` content block, so existing question-version snapshots and generic backup content-block handling retain the authoring data.
- Legacy Numerical questions without a template continue using their existing exact-text answer path.
