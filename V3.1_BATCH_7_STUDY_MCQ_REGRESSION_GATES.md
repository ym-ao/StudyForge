# V3.1 Batch 7 — Study numerical MCQ regression gates

## Scope
This batch adds a dedicated CI source-contract verifier for the Study-mode generated numerical MCQ path. It protects the already implemented behavior rather than changing study scheduling or numerical grading.

## Guarded behavior
- Only `VERIFIED` numerical templates opt into generated Study variants.
- Variant and MCQ generation use the same stable queue fingerprint + question ID seed context.
- Generated choices are selectable and checking is disabled until a choice is selected.
- Study grading continues to use the numerical engine's tolerance/unit-aware checker.
- Revealed feedback uses the generated answer and substituted explanation.
- Queue changes reset the selected answer and reveal/check state.
- Distractors remain outside the accepted tolerance.

## Compatibility and safety
- No Kotlin production source changes in this batch.
- No Room schema/migration, backup schema, app version/versionCode, FSRS, signing, or user-data changes.
- Legacy Numerical questions retain the existing exact-match fallback.
